# Security reports

For vulnerabilities affecting private data or someone else's machine, use
[GitHub private vulnerability reporting](https://github.com/phobos-dthorga/phobos-ostranauts/security/advisories/new).
Do not post secrets or unredacted exploits in public issues. If private reporting
is unavailable, open a minimal issue asking for a private contact route without
sensitive details.

Include revision/version, impact, reproduction and a synthetic example where
possible. Maintenance is best-effort for the current development version, with
no guaranteed response or old-version support window. Gameplay bugs belong in
[Issues](https://github.com/phobos-dthorga/phobos-ostranauts/issues/new/choose).
