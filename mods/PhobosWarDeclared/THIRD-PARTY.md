# Phobos' War Has Been Declared provenance

War Has Been Declared is original Phobos code under the repository licence. It
uses Phobos Framework as a separately supplied dependency; Framework retains its
own upstream adaptation notices. It adds no artwork, sounds or items.

Native damage, construction-placeholder, install-job and combat-state behaviour
was inspected locally in [Blue Bottle Games' Ostranauts](https://store.steampowered.com/developer/bluebottlegames/)
1.0.1.5. The mod reuses the game's own build sites, install jobs and navigation
stations at runtime by reference; no game asset, definition or code is copied
into the package. Game assemblies and decompiled source are excluded from
distribution. BepInEx and Unity references are resolved from the owner's
installation and are not bundled.

The shipped rebuild schematics in `schematics/` are original data under the
repository licence; players may copy and adapt them freely.
