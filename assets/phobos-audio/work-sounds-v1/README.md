# Retired procedural audio pack from this chat

and liquid-pump sounds and explicitly requested deletion of the Python audio
samples created earlier in this chat.

All **38 WAV files** have been removed: 18 candidates, 18 PCM24 masters and two
review tracks. Only files added by this chat's commit **b8331d5e** and matching
the original manifest hashes were deleted. The older Shipbreaker completion
cue was preserved.

Use the [selected washer/pump pack](../washer-motor-pump-v1/README.md) and
[current Claude handoff](../../../docs/development/machine-work-sounds-handoff.md).

The recipes and manifest here are **historical text records of removed files**,
not a current asset inventory. The synthesis source is retained as an authoring
record; it refuses to regenerate this discarded pack unless explicitly given
`--restore-retired`. Do not restore it without a new owner request.
The [removal record](../washer-motor-pump-v1/retired-session-audio.json) retains
the exact removed names, hashes and creating commit.
