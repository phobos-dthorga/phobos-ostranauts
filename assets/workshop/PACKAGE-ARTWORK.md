# Mod-menu and Workshop cover artwork

The native mod folder's `preview.png` is an original Phobos promotional cover.
It serves the native mod menu and, when the owner publishes it, the Workshop
listing. Including it does not publish a Workshop item.

**Framework, Auto Nav, Shipbreaker and Agriculture:** commissioned by phobosgekko
using ChatGPT's built-in image generation on 25 September 2026. Each is a 512 x 512
nearest-neighbour derivative of an unchanged 1254 x 1254 master archived on the
private `codex/workshop-art-masters` branch. The owner approved the cover set in
conversation. Full generation prompts are included beside this document in
`WORKSHOP-ARTWORK-PROMPTS.json`. Generated output is subject to applicable
[OpenAI terms](https://openai.com/policies/terms-of-use/).

**Manufacturing:** composed on 29 September 2026 from a scene generated with
PixelLab (`create_image_pro`, one 244 x 170 image) and the Shipbreaker cover's
frame, with the title drawn from original pixel glyphs. The scene took the
Shipbreaker cover as its style image and the mod's own V4, X2 and H2 world sprites
as design references. The prompt, seed, provider IDs and composition steps are
included in `WORKSHOP-ARTWORK-COMPOSITION.json`. Generated output is subject to
[PixelLab's terms of service](https://pixellab.ai/termsofservice).

[Blue Bottle Games' Ostranauts](https://store.steampowered.com/app/1022980/Ostranauts/)
informs the industrial pixel-art style and setting. No game textures, game
screenshots, third-party mod sprites or official logos were generation inputs.
