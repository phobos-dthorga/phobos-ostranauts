# Workshop high-resolution master archive

This branch, `codex/workshop-art-masters`, preserves the four unchanged original
cover images commissioned by phobosgekko on 25 September 2026. Do not merge this
branch into normal development branches. The smaller publication derivatives,
export script and full usage/provenance notes live in `assets/workshop/` on `main`.

`masters.json` records actual dimensions, SHA-256 hashes and generator result IDs.
`prompts.json` retains every exact generation prompt. Each original is 1254 x 1254
pixels, as returned by ChatGPT's built-in image_gen tool despite a 2048-square
request. No enlargement is presented as additional generated detail. These
originals exceed twice the 512-pixel publication size per axis.

There were four generation calls, one per selected mod. No input images were sent
to the generator. Model revision, seed and per-call price were not disclosed.
The images interpret [Blue Bottle Games' Ostranauts](https://store.steampowered.com/app/1022980/Ostranauts/)
and the project's own equipment descriptions; they contain no redistributed game
textures or official logos. They are promotional illustrations, not screenshots,
scientific evidence, an endorsement or proof of available/tested gameplay.
Agriculture carries an explicit development label. The Framework backplane is a
metaphor for shared software, not a promised new machine.

Applicable [OpenAI terms](https://openai.com/policies/terms-of-use/) govern generated
output. No independent exclusivity guarantee or new asset licence is asserted.
Keep this branch private along with the existing repository.
