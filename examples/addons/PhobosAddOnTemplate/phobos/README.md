# Where the files go

Put each override file in `phobos/<Mod>/<schema>/`, exactly as you would in
`BepInEx/config/<Mod>/<schema>/`:

- `phobos/PhobosManufacturing/outcomes/my-odds.json`
- `phobos/PhobosManufacturing/process-recipes/my-recipes.json`
- `phobos/PhobosAgriculture/crops/my-crop.json`
- `phobos/PhobosWarDeclared/schematics/my-schematic.json`

See [publishing an add-on](https://github.com/phobos-dthorga/phobos-ostranauts/blob/main/docs/publishing-an-add-on.md).
Delete this file before you publish, or keep it; the game ignores it.
